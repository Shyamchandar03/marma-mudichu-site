Privacy Policy

Last updated: 17 October 2026

This policy explains how the Marma Mudichu automation tool (the "App") handles information. The App is a private tool used only by the owner of the Marma Mudichu channel to publish the channel's own videos. It is not offered to the public.

Information the App accesses

With the channel owner's permission, the App uses Google OAuth to access the owner's YouTube account in order to: (1) upload the channel's own videos with their titles and descriptions, and (2) read public comments on the channel's own videos to find the display names of viewers who answered a mystery correctly, so they can be thanked in the next episode.

How information is used

Commenter display names are used only to credit correct solvers in a later episode of the channel. Comment text is read only to check whether it names the correct answer and is not stored. No information is sold, shared with third parties, or used for advertising.

Storage and retention

The App stores an access token in an encrypted secret store so it can upload videos. It keeps a short episode history (case titles, answers and the names already thanked) in a private repository. Viewers can ask for their name to be removed at any time using the contact below.

Google API Services

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. The App uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.

Revoking access

The channel owner can revoke the App's access at any time at myaccount.google.com/permissions.
